# Central Radio Stations geotagging
# Overview
Here, I have geo-tagged all the central radio stations from the Radio Compedium of 2023 in India. Information regarding the CRS license holder, language and purpose of the radio stations are also included.
# Methodology

I use the following API: https://rapidapi.com/navii/api/pin-codes-india to convert the pincodes mentioned in the compendium address for each of the central radio station into geographic coordinates which are then manually copulated in a separate csv file containing the central railways stations.
